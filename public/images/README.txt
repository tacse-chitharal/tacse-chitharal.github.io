PHOTOGRAPHS FOR THE WEBSITE
===========================

Drop image files into this folder and the site picks them up automatically —
no code needs to be edited.

  hero.jpg        The large picture beside "Your Journey to Public Service
                  Starts Here" on the home page.
                  Best size: about 1200 x 800 pixels, landscape.
                  Also accepted: hero.webp, hero.png, hero.jpeg

Until hero.jpg exists, the home page shows a designed navy panel instead, so
the site never looks unfinished. Add the photograph whenever you have one.

A few practical notes
---------------------
1. Keep each file under about 400 KB. A large photograph makes the page slow
   to open on a phone with a weak signal, which is most of our students.
   Any free tool such as squoosh.app will shrink a photo without visible loss.

2. Please get permission before putting a recognisable photograph of a student
   on a public website — particularly for anyone under eighteen, where the
   parent or guardian should agree.

3. Photographs of the building, the library shelves, the notice board or a
   class in progress work just as well as posed group pictures, and raise no
   permission questions at all.
